# 창원시 전기차 충전소 추천 및 수요 분산 MVP (팀 그루트)

## 1. 팀 및 프로젝트 개요
- **팀명:** 그루트 | **팀장:** 임승현 | **팀원:** 이정후, 이찬준, 이은규, 동화준 (총 5명)
- **대상 거점:** 경상남도 창원시 의창구 팔용동, 성산구 중앙동, 진해구 석동
- **핵심 기능:** 사용자의 현재 SOC, 목표 SOC, 배터리 용량, 차량 최대 수용 출력, 예상 체류 시간, 이용 시간대, 계절 시나리오를 반영해 **총 소요 시간(추가 이동 + 예상 대기 + 예상 충전)** 기준 최적 충전소와 대체 충전소를 추천하고, 피크 시간대 수요 분산 전/후 가동률 및 추정 전력·부하율을 시뮬레이션합니다.

## 2. 저장소 구성
- `index.html`: 대시보드 레이아웃 및 스크립트 로드 진입점
- `js/data.js`: 거점 샘플 데이터, 시간대/계절 시뮬레이션 상수, 한국환경공단 상태 코드 허용 목록 및 API 매핑
- `js/calculator.js`: 입력값 검증, 필요 충전량(kWh), SOC 구간별 충전 시간(분), 예상 대기 시간(분), 체류 내 완료 가능 판정(`waitMin + chargeMin <= dwellMin`)
- `js/recommender.js`: 충전소 평가, 최적/대체 추천(조건 미충족 시 총 소요 시간 최단 기준), 피크 수요 분산 시뮬레이션
- `js/ui.js`: `escapeHtml()` 적용 및 추천 카드·분산 시뮬레이션·시간대 패턴·필터/정렬 테이블 렌더링
- `js/app.js`: 상태 관리, DOM 이벤트 바인딩, API 조회 제어
- `test/run-tests.js`: 계산·예외 처리·대체 추천·상태 코드 경계·API 변형·분산 시뮬레이션 단위 테스트

## 3. 실행 및 테스트 방법
### 필수 환경
- 웹 브라우저(Chrome, Edge 등) 또는 GitHub Pages
- 단위 테스트 실행 시 **Node.js (v18 이상 권장)** 설치 필요

### 단위 테스트 실행 절차
1. 저장소를 내려받거나 터미널에서 프로젝트 루트 폴더로 이동합니다.
2. 아래 명령어를 실행합니다.

```bash
node test/run-tests.js
